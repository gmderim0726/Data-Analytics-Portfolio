# Financial Performance, Analysis and Planning

## The problem

In corporate finance, raw accounting data (General Ledger) is often complex and difficult to interpret for strategic decision-making. The challenge is to transform thousands of transactional records into clear, actionable insights regarding a company's profitability, liquidity, and solvency. This project solves that by providing an end-to-end solution: a Python-based synthetic financial data generator built on double-entry bookkeeping principles, and an interactive Power BI dashboard to monitor the Income Statement, Balance Sheet, and Cash Flow Statement in real time.

## Source Data

The dataset is entirely generated using a custom Python script (pandas, random, datetime). It simulates a realistic corporate environment by generating daily transactions for a fictitious company over the year 2025. The script creates structured Fact and Dimension tables, including:

- General Ledger (GL): Double-entry accounting records for revenues, expenses, assets, and liabilities.

- Sales & Costs: Transactional data based on product and customer dimensions.

- Budgets: Departmental budget allocations.

## Key questions explored

1. Profitability (Income Statement): How is the gross revenue consumed by operating expenses and cost of goods sold (COGS) to reach the net income across different quarters?

2. Financial Health & Liquidity (Balance Sheet): What is the company's debt-to-asset ratio, and how are the assets distributed between current liquidity (Cash/Inventory) and fixed assets (Equipment)?

3. Cash Generation (Cash Flow Statement): How is the company's actual cash being generated and consumed across Operational, Investing, and Financing activities throughout the year?

## Getting started

To get start with Financial Analysis, you can follow these steps:

1. Clone this repository to your local machine.

2. Ensure you have Python installed, along with the pandas library.

3. Run the Python script to generate the synthetic datasets and export them to your local environment (e.g., as CSV files or into a SQL database).
